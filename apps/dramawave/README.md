# 剧浪 DramaWave · 竖屏短剧平台（MVP）

DramaBox 式竖屏短剧平台的可运行原型：创作者上传剧集，观众按集解锁，平台按**每集收入的 1%**抽成。

## 运行

```bash
npm install --include=dev
npm run dev      # http://127.0.0.1:5220
npm run build
```

## 已实现

**观众端**
- 发现页：主推位、标签筛选、剧集网格、继续观看
- 剧集详情：简介、标签、剧集列表、免费/锁定状态
- 全屏播放：竖屏视频、剧集切换、自动下一集、锁定集提示
- 解锁：扣币、写入账单、立即播放
- 钱包：余额、测试充值、账单（充值/解锁/提现）、平台抽成统计

**创作端**
- 从 StoryLoom 导入项目 JSON：用分镜图 + 时长 + 对白在浏览器内合成竖屏 WebM，直接发布为剧集
- 工作室名称
- 新建剧集（剧名/简介/标签/封面上传）
- 上传剧集视频（本地 IndexedDB，支持 mp4/webm/mov，≤200MB）
- 单集发布/下架、删除剧集或单集
- 数据看板：播放、解锁次数、总收入、平台抽成（1%）、可提现
- 提现申请（演示，不真实打款）

**分账规则**
- 1 币 = ¥0.10
- 每集单独结算：`平台 = round(该集收入 × 1%)`，创作者拿剩余 99%
- 例：30 币（¥3.00）→ 平台 ¥0.03，创作者 ¥2.97
- 免费集不产生分账

## 数据存储

- 剧集元数据、钱包、账单：localStorage
- 视频二进制：IndexedDB（`dramawave-blobs`）
- 封面：压缩到 720px 宽后存 localStorage
- 没有服务器，换浏览器/清缓存会丢数据

## 运行日志

- 顶部「日志」（移动端底部导航「日志」）打开运行日志，播放器里也有入口
- 自动记录：启动、播放、解锁、充值、提现、上传、StoryLoom 导入与合成、存储失败、未捕获异常、`console.error`
- 支持按「警告 / 错误」筛选、下载 txt、清空；最多 200 条，只存在当前浏览器
- 出现错误时顶部按钮显示红色计数，可直接打开查看
- 直达链接：http://127.0.0.1:5220/?logs=1
- 遇到问题时点「下载」，把日志文件发给开发者即可定位

## 上线还缺什么

1. **账号与角色**：注册/登录、创作者认证、观众账户
2. **服务端存储与转码**：对象存储 + CDN + HLS 转码，替代本地 IndexedDB
3. **真实支付**：支付渠道、订单、退款、对账；当前充值/提现都是模拟
4. **分账与结算**：创作者余额、提现审核、税务与发票
5. **内容安全**：上传审核、版权投诉、下架机制
6. **防盗链/DRM**：签名播放地址、防录屏策略

## 与 StoryLoom 的链路

1. StoryLoom 完成分镜并生成图片
2. 「导出」页点「发布到剧浪」下载项目 JSON
3. 剧浪 → 创作者中心 → 从 StoryLoom 导入 → 选 JSON → 设价格 → 合成并发布
4. 观众解锁，按每集 1% 分账

合成是 Canvas 捕获 + MediaRecorder 实时录制（720×1280、24fps），耗时约等于成片时长。录制器会按真实时间打点，避免掉帧导致成片变短。

## 已知限制

- 视频只存在当前浏览器；其他设备看不到
- 合成结果是 VP9 WebM，个别 Safari 版本可能无法播放；正式上线应转成 H.264 MP4 并做 HLS 切片
- 提现按钮只写一条负数账单，没有真实资金流
- 没有登录，创作者身份是本地名称，可被任意修改
- 未接支付，平台抽成是账本层面的计算
- 1% 抽成按分四舍五入，极小金额（如 ¥2.50）会向上取整到 ¥0.03
