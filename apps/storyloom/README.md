# StoryLoom · AI 短剧分镜工坊

纯前端 MVP：剧本拆分 → 角色设定 → 分镜提示词 → 出图/上传 → 时间线预览 → 导出素材包。
没有后端、没有账号、没有支付。

## 运行

```bash
npm install --include=dev
npm run dev      # http://127.0.0.1:5210
npm run build
```

## 已实现

- 项目库：新建、切换、导入 JSON、本地自动保存（localStorage）
- 剧本页：片名/梗概/画幅/视觉风格，剧本编辑与「拆分为分镜」
- 拆分规则：场景行识别（内景/外景/第 N 场）、空行分段、「角色：台词」抽取
- 角色表：名字、中文设定、英文外形提示词；剧本里出现角色名会自动拼进提示词
- 分镜板：逐镜提示词、时长、seed、生成/重生成、上传本地图、删除、补齐空提示词
- 生成：Pollinations 免费端点（无需 Key，有频率/额度限制），失败会显示原因并保留重试
- 预览：按镜头时长播放静帧，带缓慢推拉与字幕，可拖动进度
- 导出：项目 JSON、分镜 CSV、字幕 SRT、素材包 ZIP（图片 + 表格 + 字幕 + 提示词）
- 发布到剧浪：导出项目 JSON，去剧浪创作者中心导入，浏览器内合成竖屏视频并上架

## 已知限制

- 免费出图端点不稳定：会返回 402/429/503，界面会提示，可直接重试或上传本地图。
- 预览是静帧 + 运镜模拟，不是视频生成；成片需在剪辑软件里合成。
- 角色一致性靠重复的英文外形描述和连续 seed，不保证跨镜头完全一致。
- 图片以 dataURL 存在 localStorage，图片多时可能触发存储上限。
